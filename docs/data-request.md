# Анкета компании — данные для DocFlow

Заполняется **отдельно на каждую из 4 компаний**. Это ответ на вопрос Q16 в `docs/questions.md`:
пока анкеты нет, реквизиты в системе вымышленные, и ни один документ из неё нельзя подписать.

Как пользоваться:

- Копируете файл: `docs/data/<компания>.md`, заполняете, присылаете.
- Не знаете ответ — пишите `?`. Пустая строка и `?` — разные вещи: первое читается как «нет данных»,
  второе как «надо выяснить».
- Что-то неприменимо — пишите `нет`. Это тоже ответ, и он закрывает поле.
- **Персональные данные (ИИН, оклады, адреса, даты рождения) в этот файл не вписывайте.**
  Для них — раздел 17.

У каждой группы есть строка «нужно для»: это документы из вашего же списка
(`catalog/source/documents-list.txt`) или экраны сайта, которые без этих данных заполнить нечем.

## 17. Персональные данные — отдельным каналом

**В этот файл не вписывать. Не присылать в мессенджере.**

Понадобятся по каждому работнику: ИИН, дата рождения, адрес проживания, оклад, контакты,
номер и дата трудового договора, дата приёма.

В системе они шифруются в базе, на экране маскируются, а просмотр полного значения пишется
в журнал. До того как система заработает, передавать их нужно так, как это принято у вас для
кадровых документов, — не файлом в чате.

Отдельно: **согласие на обработку персональных данных** — в вашем списке документов оно есть.
Без него собирать ИИН и адреса нельзя.

- приказ о приёме на работу: `________`
- трудовой договор: `________`
- договор оказания услуг: `________`
- доверенность: `________`
- счёт на оплату или акт выполненных работ: `________`

**Почему это важнее анкеты:** в образце видна ваша формулировка. Тексты шаблонов в системе сейчас
помечены «ЧЕРНОВИК — ПРОВЕРИТЬ ЮРИСТУ» именно потому, что написаны по общему виду, а не по вашим
документам. Один настоящий приказ заменяет десяток вопросов.

## Что можно прислать первым

Если собирать всё сразу долго, порядок такой — каждый пункт сам по себе даёт результат:

1. Разделы 1, 2, 5 по одной компании — и её бланк перестанет быть вымышленным.
2. Образец приказа в `.docx` (раздел 18) — по нему выправится вёрстка листа.
3. Раздел 11 — и номер в реестре станет проверяемым, а не просто текстом.
4. Раздел 9 — и должности в приказах перестанут вводиться руками.
5. Остальное.
