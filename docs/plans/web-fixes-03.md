## Риски

- **Удаление навсегда необратимо.** Защита: только из корзины, только
  директор и администратор, отдельное подтверждение с текстом «без возврата»,
  запись в журнале.
- **Шаблон, изменённый после выпуска документа**, переписал бы документ.
  Поэтому сохранённый документ держит снимок шаблона (`CLAUDE.md`, п. 3.4).
- **Текст шаблона из конструктора – не проверенный юристом текст.** Шаблон
  помечается `reviewed: false`, интерфейс это показывает.
- **Замена казахских букв в русском написании** меняет написание имени.
  Выпущенные документы не меняются: у них снимок карточек. Казахское
  написание сохраняется в своём поле.
- **Бэкап отправляет код на GitHub.** Пока репозиторий публичный, задача не
  включается.
