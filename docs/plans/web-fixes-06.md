# Правка 12.10: PDF с текстом вместо картинки

Просьба: «шаблоны переделай не на фото, а на текст полноценный, и самое
главное – когда скачиваешь документ, там фото вместо текста, переделай его
на текст».

## Разбор

- Шаблоны в системе – уже текст: лист `DocumentSheet` свёрстан HTML.
  «Фото» появлялось только в скачанном файле: `exportPdf` снимал лист
  картинкой (`html2canvas-pro` → JPEG → jsPDF, ADR 0001).
- Обе части просьбы поэтому закрывает одна правка – PDF с текстом. Если
  под «шаблонами» имелось в виду что-то другое (например, скачивание
  Word), это отдельная задача.

## Что сделано

| Файл | Что |
|---|---|
| `web/src/features/documents/exportPdf.ts` | лист переносится в PDF: слова – текстом на своих местах, рамки – линиями, фон, логотип; обрезка разорванных между листами строк; дефисы переноса |
| `web/src/features/documents/pdfLayout.ts` | расчёты без браузера: слова, начертание, базовая линия, ширина, обрезка, дефис переноса, цвет |
| `web/src/features/documents/pdfFonts.ts` | загрузка Tinos в jsPDF, только нужные начертания |
| `web/src/assets/fonts/tinos-*.ttf`, `styles/fonts.css`, `DocumentSheet.module.css` | шрифт Tinos; в листе – запасной после Times New Roman |
| `web/package.json`, `vite.config.ts` | `html2canvas-pro` удалён |
| `web/src/security/csp.ts`, `deploy/Caddyfile` | снято исключение по хешу в `style-src` |
| `docs/adr/0003-pdf-s-tekstom.md` | решение и варианты; ADR 0001 помечен заменённым |

## Тесты

- `pdfLayout.test.ts` – слова, начертания, базовая линия, подгонка ширины,
  окно обрезки, логотип в рамке, дефис переноса на данных, снятых с Chrome,
  цвет, прописные с казахскими буквами.
- `pdfFonts.test.ts` – во всех четырёх начертаниях есть казахские и русские
  буквы и знаки документов; казахские буквы в PDF – текст с картой Unicode;
  в файл попадают только использованные знаки.
- `csp.test.ts` – стили только со своего адреса, без исключений.

## Проверка в браузере

Стенд во временной папке (в репозиторий не входит): настоящие
`DocumentSheet` и `exportPdf` на семи шаблонах в Chrome, PDF разобран
PyMuPDF и `pdftotext`, страницы отрисованы и сравнены с листом на экране.

## Риски

- Переносятся текст, фон, сплошные рамки, картинки. Тени, градиенты,
  скругления и SVG в лист не входят; появятся – дополнить `exportPdf`.
- Дефис переноса берётся с места, которое отдаёт Chrome. В другом браузере
  при включённых переносах дефис в PDF может пропасть – текст при этом
  остаётся на своих местах.
