# Каталог

Здесь лежат **данные**, а не код: разделы, профили доступа, роли, серии номеров,
описания документов и шаблоны. Новый документ или роль добавляется правкой этих
файлов — программист для этого не нужен.

Каждое изменение проверяется командой `make check-catalog`.

## Файлы

| Файл | Что описывает |
|---|---|
| `sections.yaml` | 11 разделов и их подразделы. Из них строится меню и экран «Создать документ» |
| `profiles.yaml` | 6 профилей доступа: насколько узок круг людей у документа |
| `roles.yaml` | системные роли и их права; загружаются процессом `seed` |
| `series.yaml` | серии номеров. **Ждёт подтверждения** — см. Q5 в `docs/questions.md` |
| `documents/NN-<раздел>.yaml` | описание каждого документа раздела |
| `templates/<раздел>/<документ>/` | `template.ru.docx`, `fields.yaml` |
| `source/documents-list.txt` | исходный список документов от заказчика; правится только человеком |

## Как устроено право доступа

Право — это три части: `<раздел>.<профиль>.<действие>`.

```
hr.sensitive.view        видеть документы узкого круга в кадрах
finance.standard.create  создавать обычные финансовые документы
*.*.approve              утверждать что угодно (право директора)
```

Разделы берутся из `sections.yaml`, профили — из `profiles.yaml`, действия
перечислены в `roles.yaml`.

## Как добавить документ

1. Найдите его в `source/documents-list.txt` — придумывать документы не нужно.
2. Добавьте запись в `documents/NN-<раздел>.yaml`: тип, профиль, серия, маршрут
   согласования, срок хранения, разделы показа.
3. Если это шаблон — создайте `templates/<раздел>/<документ>/` с `fields.yaml`
   и `template.ru.docx`.
4. Текст документа пометьте `ЧЕРНОВИК ТЕКСТА — ПРОВЕРИТЬ ЮРИСТУ`. Реквизиты
   законов и номера статей не выдумывайте: оставьте поле для юриста.
5. Запустите `make check-catalog`.

## Один документ в нескольких разделах

Трудовой договор, доверенность, NDA встречаются в разных разделах. Дубликат
создавать не нужно: у документа есть **один** владеющий раздел (`owner_section`),
по которому проверяется право, и список разделов показа (`display_sections`),
который влияет только на то, где документ виден в меню.

Это правило ждёт подтверждения — Q7 в `docs/questions.md`.

## Состояние наполнения

Заполнены: `sections.yaml`, `profiles.yaml`, `roles.yaml`, `series.yaml` (черновик).

Не заполнены: `documents/`, `templates/`. Они наполняются по разделам на этапе 8
роадмапа, один раздел — один PR.
