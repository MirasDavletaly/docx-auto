# Шрифты сайта

Лежат в самом сайте, а не берутся с Google Fonts: заход на сайт не сообщает
Google адрес человека, сайт не зависит от чужого сервера, а политика
безопасности (CSP) разрешает только свой адрес. Решение – проверка
безопасности 29.09.2026 (`docs/security-review-2026-09.md`).

| Шрифт | Где | Лицензия |
|---|---|---|
| Golos Text (переменный, 400–700) | интерфейс | SIL Open Font License 1.1 |
| PT Serif (400, 700, 400 курсив) | лист документа | SIL Open Font License 1.1 |
| JetBrains Mono (переменный, 400–500) | номера, суммы | SIL Open Font License 1.1 |
| Tinos (400, 700, оба курсивом) | текст в PDF; запасной шрифт листа | SIL Open Font License 1.1 |

Наборы символов: кириллица, расширенная кириллица (казахские ә ғ қ ң ө ұ ү
һ і), латиница и расширенная латиница. Файлы – те же woff2, что отдаёт
Google Fonts; подключаются в `styles/fonts.css`.

Tinos – целые файлы TrueType (`tinos-*.ttf`) из `github.com/google/fonts`,
`ofl/tinos`: jsPDF встраивает только TrueType. По меркам он совпадает с
Times New Roman, которым набран лист, – поэтому PDF совпадает с листом.
Почему так и контрольные суммы файлов – `docs/adr/0003-pdf-s-tekstom.md`.

Лицензия OFL разрешает встраивать и распространять шрифты вместе с
программой; текст – https://openfontlicense.org.
